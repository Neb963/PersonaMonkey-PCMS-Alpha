# Historical donor records

Alpha's only product and execution authority is its accepted specification,
contracts, plan, policies, gates, acceptance matrix and root `AGENTS.md`.

All inherited donor architecture, ADRs, roadmap, implementation/v1 records,
claims and evidence are **history only**, including records retained at original
paths for inherited test/harness compatibility. Their ACCEPTED/LIVE labels do not
establish any Alpha acceptance. No donor successor phase may be selected here.

`donor/` is the exact 726-file donor source snapshot pinned by
`docs/provenance/alpha-donor.json`. It includes original governance and tests so
the donor's real verification remains reproducible after authorized Alpha edits.
Nested AGENTS files in frozen snapshots are historical source, not Alpha authority.
Never edit the snapshots to make a failing check pass.

`docs/provenance/alpha-design/` preserves the seven approved seed files before
G0's explicit acceptance/status and executable-governance additions. The accepted
active copies live at their specified Alpha paths. Offline prompts are convenience
copies; their phase assignment never overrides the current main plan or a claim.
