# PersonaMonkey v0.6.1 — persona data portability

v0.6.1 is the universal data-management milestone immediately before PCMS v0.7. It builds on the v0.6 workflow portability release without changing routing semantics, native Mullvad transport, workflow execution contracts, the persisted state schema, or the stable Gecko extension ID.

## Persona-scoped cookies

Managed personas now expose a cookie manager from **Profiles → Edit**. Cookie reads and mutations always use the selected Firefox contextual identity's exact `cookieStoreId`.

The UI supports:

- listing and filtering one persona's cookies;
- editing common cookie fields while preserving Firefox isolation metadata;
- deleting one cookie;
- clearing every cookie in the selected persona;
- clearing a domain and its subdomains in the selected persona only.

Regression coverage verifies that matching cookies in another persona are not read, edited, or cleared.

## Versioned complete and selective backups

The **Data & backup** tab introduces the versioned `*.personamonkey-backup.json` format.

Complete backups include the portable extension graph plus persona cookies, persistent userscript/GM values, route credentials, and automation history. Complete backups require password-based authenticated encryption using PBKDF2-HMAC-SHA-256 and AES-256-GCM.

Selective export supports settings, selected personas, userscripts, workflows, cookies, GM values, history, and route credentials. Referenced routes/scripts/personas are closed as dependencies so exported objects do not contain broken internal references.

WireGuard private configuration remains outside the backup format.

## Portable import

Backup identity is independent of local Firefox `firefox-container-*` IDs. Personas, routes, scripts, and workflows use backup-local keys and are remapped to the destination installation during import.

Import is deliberately inspect-first:

1. parse/decrypt and validate the file;
2. show inventory and suggested persona mappings;
3. require explicit confirmation;
4. create/reuse contextual identities and apply remapped data.

Merge mode preserves unrelated local objects and resolves collisions. Replace mode resets only component classes represented in the backup. Existing Firefox containers are not silently deleted.

Protected routing remains fail-closed when imported route dependencies cannot be restored safely.

## Reinstall recovery

Ordinary extension updates continue to retain `storage.local` under the stable extension ID.

For a genuinely fresh/reinstalled extension state, the background bootstrap can restore a quota-aware non-sensitive control-plane snapshot from Firefox Sync before normal extension initialization.

The Sync snapshot may contain settings, personas, redacted route definitions, userscripts, and workflows. It excludes cookies, route credentials, GM values, automation history, and WireGuard private material.

Recovery is complete-or-unavailable: if the full non-sensitive graph cannot fit within the safe Sync budget, PersonaMonkey does not write a partial graph.

## UI polish

The options UI received a cross-extension hierarchy pass rather than a backup-only restyle:

- consistent section headings and explanatory context;
- stronger distinction between routine, primary, destructive, warning, and legacy actions;
- clearer list/editor surfaces for userscripts and workflows;
- improved route, security, diagnostics, and profile layouts;
- dedicated cookie editor styling;
- explicit complete/selective/import/recovery hierarchy in Data & backup;
- de-emphasized legacy JSON compatibility controls;
- keyboard focus treatment and responsive action wrapping;
- improved narrow-window navigation and layout;
- refined popup hierarchy and egress-test action.

Existing controller element IDs were preserved so the visual refactor does not create a parallel UI controller or invalidate the existing event contracts.

## Verification

The release gate consists of:

```bash
node scripts/test-extension.mjs
node scripts/test-options-browser.mjs
node scripts/test-data-management-browser.mjs
node scripts/validate-extension.mjs
node scripts/build-extension.mjs
node scripts/build-workflow-examples.mjs
```

Direct regressions cover cookie-store isolation, encrypted backup round-trips, import remapping/collisions, and Firefox Sync recovery integrity. Browser gates exercise the actual options modules with deterministic WebExtension stubs for both the Automations/package/diagnostics surface and the persona-cookie/data-management surface.

Installed LibreWolf testing remains the final environment-specific verification for real contextual-identity cookies, Firefox Sync account behavior, and complete export/reinstall/restore behavior.
