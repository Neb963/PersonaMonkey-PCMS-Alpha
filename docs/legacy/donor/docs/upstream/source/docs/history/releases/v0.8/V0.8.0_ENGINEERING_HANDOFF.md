## What changed

- **Userscript isolation and privileges:** isolated-world IDs now use the full script ID hash; privileged grants are revalidated at privileged operations and collisions fail closed. MAIN-world completion does not expose a privileged completion token, and page-origin signals are untrusted.
- **Redirect handling:** direct GM fetch paths fail closed on redirect. The native bridge rechecks each script's `@connect` permission on every redirect and strips sensitive headers across origins. Downloads fetch bounded bytes once before converting them to a data URL.
- **Route health:** verification belongs to the exact active route configuration and protection settings, including strict proxy verification. Stale and delayed storage echoes cannot preserve an obsolete healthy result.
- **Workflow orchestration:** tab ownership is explicit; signals, jobs, history, and packages are bounded. Active jobs are not evicted by history limits, writes are serialized, and failed starts roll back persistence.
- **Management contract and packaging:** command schemas and capability fallbacks are explicit, public projections are sanitized, batch revision guards are enforced, and package fixtures/runtime contracts are aligned.
- **Release evidence:** exact artifact hashes and remaining gates are recorded in [the current release gate record](V0.8.0_CURRENT_RELEASE_GATES.md).

Preserve the Persona OS/PCMS boundary and the existing stable extension ID. Workstream G was deliberately excluded; do not fold it into a release follow-up without a separately scoped design.
